# Third-Party Licenses

ScratchBook bundles the color palettes of the following third-party themes. The colors
themselves are reproduced from each project's published palette; ScratchBook does not
include any of their code.

Each project is licensed under the MIT License.

| Theme | Project | Source of color values |
| --- | --- | --- |
| Catppuccin (Mocha, Macchiato, Frappé, Latte) | [catppuccin/palette](https://github.com/catppuccin/palette) | `palette.json` |
| Dracula | [dracula/dracula-theme](https://github.com/dracula/dracula-theme) | Palette definition in the project README |
| Nord | [nordtheme/nord](https://github.com/nordtheme/nord) | [Nord color palette documentation](https://www.nordtheme.com/docs/colors-and-palettes) |
| Gruvbox (Dark, Light) | [morhetz/gruvbox](https://github.com/morhetz/gruvbox) | `colors/gruvbox.vim` |
| Tokyo Night, Tokyo Night Light | [enkia/tokyo-night-vscode-theme](https://github.com/enkia/tokyo-night-vscode-theme) | Theme JSON files |
| Solarized (Dark, Light) | [altercation/solarized](https://github.com/altercation/solarized) | [Solarized palette](https://ethanschoonover.com/solarized/) |
| One Dark | [atom/one-dark-syntax](https://github.com/atom/one-dark-syntax) | `styles/colors.less` |
| One Light | [atom/one-light-syntax](https://github.com/atom/one-light-syntax) | `styles/colors.less` |
| Rosé Pine (Main, Moon, Dawn) | [rose-pine/palette](https://github.com/rose-pine/palette) | `palette.json` |
| Everforest (Dark, Light) | [sainnhe/everforest](https://github.com/sainnhe/everforest) | `palette.md` |
| Kanagawa | [rebelot/kanagawa.nvim](https://github.com/rebelot/kanagawa.nvim) | `lua/kanagawa/colors.lua` |
